# ⭐ Projeto em Destaque

## ⚖️ JusTraduz

O **JusTraduz** é uma plataforma web desenvolvida em equipe com o objetivo de tornar documentos e informações jurídicas mais acessíveis.

O sistema utiliza **Inteligência Artificial para analisar e traduzir conteúdos jurídicos para uma linguagem mais simples**, além de permitir a conexão entre usuários e profissionais do Direito.

A plataforma conta com diferentes níveis de acesso para **clientes, advogados, estagiários e administradores**, incluindo recursos como análise de documentos, histórico, solicitações de atendimento, chat e gerenciamento de usuários.

### 🛠️ Tecnologias utilizadas

**Backend:** PHP • Python • Flask
**Frontend:** HTML • CSS • JavaScript
**Banco de Dados:** MySQL
**Integrações:** Inteligência Artificial • APIs externas
**Versionamento:** Git • GitHub
